# Security Policy

## Reporting a vulnerability

Please don't report security problems in public issues.

Use **Report a vulnerability** on this repository's **Security** tab. The report is private: only
the maintainers of this repository can see it. Include what you found, how to reproduce it, and
what it lets someone do.

anoncat started from a copy of Tuwunel's source code, but it is a separate project. Please send
reports about anoncat here, not to the Tuwunel developers. If a problem is in code anoncat shares
with Tuwunel and also affects Tuwunel, we will pass it on to them.

## Supported versions

Only the latest commit on the `anoncat` branch is supported.
